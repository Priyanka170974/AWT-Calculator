# 🧮 AWT Calculator

### ☕ Turning Java code into calculations!

A simple, interactive **Calculator GUI** built using **Java AWT**.  
This project is designed to practice GUI development, event handling, and user interaction in Java while keeping the interface simple and easy to use.

---

## ✨ What's Inside?

🔢 **Basic Calculations**  
Perform addition, subtraction, multiplication, and division.

🖥️ **Graphical User Interface**  
Built with Java's **AWT components** for a desktop-based experience.

🖱️ **Interactive Buttons**  
Every button action is handled using Java event handling.

⚡ **Instant Results**  
Enter your numbers, choose an operation, and get the result instantly!
